③ 查询统计命令（check）
check → 等同于 check 0930 2130，统计今天09:30～21:30的非 book 订单总数、总金额和各店数据。
check 0930-2130、check 0930 2130 → 统计指定时段；check 2100 0200 → 支持跨午夜，统计当日21:00至次日02:00；check 0900 或 check 0900- → 从09:00统计到当前时间。
时段统计会显示在解析结果和「今日概览[D]」中；每家店卡片下方紧跟该店理疗师列表，并可切换“订单数/金额”一次显示一种指标。可用 Ctrl+, / Ctrl+. 切换日期，Ctrl+M 回到今天。book预约不计入时段统计。
check book 或 check books → 查询所有日期的预约，按日期从新到旧、同一天按时间从晚到早排列；check 10-20 book → 查询指定日期的预约。
check truda → 今天 truda 的普通订单和预约；check 7 → 今天7号店全部订单；check 10-1 truda → 指定日期理疗师订单。
查询结果每条订单紧凑显示一行；顶部汇总订单总数、金额总额、序号范围与缺号情况，以及订单时间跨度。未知价格计入订单数，不计入金额总额。
v152：所有 check 查询结果统一按日期、时间、订单序号逆序排列，最新时间显示在最上面；预约轨道未来仍为蓝色、接近时间为黄色、进行中改为浅冷色青蓝、已完成保持更透明的灰色，普通订单的绿色/灰色规则不变。
接线订单标记 j：4 name/5/240/60/2/接线/2020 或 4 name/5/240/60/2接线,2020 均规范为 4 name/5/240/60/2j,2020，显示红色电话图标 ☎。点击订单回填时保留 j 标记。
自约标记 y：房间字段可写 2y、2自约 或单独写 /自约，规范后会保留 y；显示图标 📞，界面不再附加“自约”文字。点击自约订单回填录入框时会保留标记，例如 7 mia,2,200,60,2y,1206。
银行转账 b、刷卡 c、VIP v、接线 j、自约 y、蜂蜜 h：六类标记支持任意顺序、连续组合或用空格分隔，例如 2vlp自约刷卡转账接线、2接线 vip 刷卡，也支持独立字段 /vip刷卡转账接线自约。vlp 自动按 vip 识别。对应图标为 🏦、💳、♛、☎、📞、🍯；自约只显示 📞。每种标记最多记录一次，内部标记为 b/c/v/j/y/h，支持 check b/c/v/j/y/h 单标记查询。3-4位尾号后也可直接带标记，例如 1289b 表示客人尾号1289并使用银行转账，不会把1289误识别成房号。VIP 的 ♛ 显示放大约1.8倍。
色块 Shift 点击（v179）：按住 Shift 并左键点击普通订单，会清空录入框并复制客户可读描述，例如 4号店 理疗师neha 序号2 金额250 时长60 理疗室1 ♛ 11:32开始；VIP用皇冠♛显示。预约订单继续使用原有广告预约描述；日期不是今天时附带预约日期。普通左键行为不变。
微信群自然语言预约（v173）：“半小时左右预约”“十分钟左右有约”“20分钟左右预约”等相对时间，以该条微信消息时间为基准计算；明确钟点如“5:00预约”按消息时段推断下午/上午，例如15:43收到“5:00预约”识别为17:00。
预约尾号与时长（v173）：金额为空时，跳过空占位字段，将第一个非空数字识别为时长；例如 7 lily,,,60,0298,1440 中60为停留时长、0298为客人尾号，不作为理疗室号。
理疗室位置的4位数字（v176）：出现在理疗室位置的4位纯数字一律识别为客人电话尾号，不作为房间号。例如 4 gui,,,30,4389,1220 表示30分钟、客人尾号4389、12:20到，房间留空。
省略序号的空字段格式（v177）：例如 4 gui,,,30,4389,12，序号由系统按店铺、理疗师及日期自动分配，金额未知，时长30分钟，客人尾号4389，最后的12表示从解析时刻起12分钟后到；理疗室留空。
v178 逆向字段解析：从末尾时间向前识别。4位数字为HHMM，3位数字为旧式HMM，1～2位数字为当前时间后N分钟；时间前4位数字为客人尾号，1位数字为理疗室，2位数字按5分钟梯度判断时长，非5分钟梯度优先作为理疗室；3位数字为备注。金额通常为50以上的2～3位数，也允许4位数（4位金额要求时长至少3位）；低于50不作为金额。时长缺失、金额缺失分别显示未知；序号缺失自动分配。
check book Shift+左键（v176）：在预约查询结果中按住 Shift 点击预约条目，会像轨道预约块一样清空输入框、填入客人友好的预约描述，并复制相同内容到剪贴板；普通左键行为保持不变。
微信群「外卖」上门订单：消息 5/外卖 自动按序号5、$350、60分钟解析，房间号留空；消息 5/外卖转帐 自动增加银行转账标记 b。外卖订单最低按350元/60分钟处理，允许在外卖后组合 b/y/c/v/j/h，例如 5/外卖转帐ycvjh；微信消息时间自动作为最后一个字段。
多标记组合与场外订单：by 仍表示银行转账、自约和场外订单。j/v/b/c/y/h 可以单独使用或任意组合，例如 jv、bc、jvbc；输入 5 qian,1,400,60,jv,0018 会识别为接线＋VIP，店铺编号不影响标签识别。标签可同时记录银行转账、刷卡等支付方式。真实订单的序号、金额、时长、房间/标记、开始时间均会保留。
check 10-5 10-20 qian → 查询理疗师 qian 在10月5日至10月20日（含起止日）的订单，按日期从新到旧分组；每天先显示当日订单数与金额合计，再列出当日订单详情。
仅名字和时间的短结构：4 kitty,1100 表示未来11:00的自约；4 kitty,20 表示从解析时刻起20分钟后的自约。目标时刻仍在未来时会自动补上 kittybook 名称和序号，价格、真实时长及客人尾号保持未知/空白（轨道以60分钟占位）。点击轨道色块会回填完整的序号、空金额/时长、y、时间和末尾 x，方便后续处理。过去或无效的绝对时刻仍按解析失败条目处理，不会计入真实订单。
check y 查询自约，check b 查询银行转账，check c 查询刷卡，check v 查询 VIP，check j 查询接线订单，check h 查询蜂蜜订单；这些查询及 check bcvjh 等组合查询均按日期从新到旧逐日汇总；每位理疗师标题后显示当前查询标记图标及该组订单数量，每日先显示订单数和金额，再按理疗师姓名分组显示详情，并保留右侧安全边距；支持 check bc、check jvbch 等标签组合查询，组合查询要求订单同时具备命令中列出的全部标签。同一订单若有 b+c，会同时出现在 check b、check c 和 check bc 中。查询共用日期、日期范围、店铺和理疗师筛选逻辑。by 旧格式仍兼容银行转账、自约和场外查询。顶部可切换订单总数或金额总和；未知价格计入订单数，不计入金额。
标记查询日期与店铺筛选（v182）：check b 10-5 10-10 7 查询10月5日至10月10日7号店银行转账订单；check b 10-5 10-10 查询该日期范围内所有店铺的银行转账订单；check b 10-7 查询10月7日所有店铺的银行转账订单；check b 7 查询今天7号店银行转账订单。日期范围、单日、店铺和理疗师筛选可组合使用。结果先显示总订单数及金额，再按日期从新到旧显示每日汇总，详情按理疗师姓名分组、组内按时间从晚到早排列。没有匹配订单时仍显示查询标题及空结果提示。
确定订单金额/时长识别（v189）：当天过去或当前时间的订单不识别尾号；序号后的金额与时长允许顺序变化，按金额较大、时长较小及常见收费梯度判断，兼容 $50/5分钟、$200/$250/$280/$350 每60分钟及中间的整数倍金额。
修改已有订单（v189）：输入明确序号及当天已过去的四位时间，例如 4 alma,7,1000,300,3,1427，将按店铺、理疗师、日期和序号修改原订单；找不到原订单时只提示，不会误新增。
微信时间格式及昵称模糊匹配兼容（v189）：支持 2026/11/04 下午1:05、2026/11/04 上午9:30、2026/11/04 13:05 等格式，自动转换为24小时制订单时间。
Check 日期星期显示（v184）：按订单日期自动显示星期，例如 2026-11-03 周二　当日 3 单金额合计 ¥650.00；适用于按天汇总的 Check 查询，不改变订单统计与排序。
check 分页：结果超过30项时分页显示。带按天汇总的查询按完整日期分页，不会在同一天的订单中间断开；必要时单页可超过30项，下一页从另一天开始，并保留当天订单数和金额汇总。
check # → 检查所有日期、所有店铺和理疗师的序号缺口；check # 10-17 → 只检查指定日期；check # daisy → 只检查指定理疗师；check # 10-17 daisy → 同时按日期和理疗师筛选。可用逗号指定多位理疗师。
序号缺口按“日期＋店铺＋理疗师”分别检查，显示缺失序号，以及前一个和后一个实际序号的时间；结果超过30处时分页显示。
日期支持 10-1、10/1、10月1日、2026-10-1。查询只读取数据，不新增、修改或删除订单。
④ 理疗师折线图命令（chart）
chart [天数] 姓名1[,姓名2,姓名3] [o/m] → 绘制折线图，统计范围包含今天；最多比较3位理疗师。前面的天数可以省略，默认7天。
chart 7 truda → 最近7天 truda 的订单数；chart 7 truda,ella o → 最近7天比较两人的订单数。
chart 30 truda m → 最近30天 truda 的金额；chart 60 truda,ella m → 最近60天比较两人的金额。图表上可切换“按日 / 按周 / 按月”，统计日期范围不变，只改变汇总粒度。
末尾 o = orders（订单数）；m = money（金额）。省略指标时默认订单数；省略天数时默认最近7天。天数支持1～365。
图表上方同时显示该范围的订单总数和金额总数。所有 chart 统计都排除 book 预约和已取消订单。价格未知的订单计入订单数，但不计入金额。单人图表右侧标注 orders 或 dollars；多人图表右侧标注姓名。
时段分布图会在容器内自适应显示，不使用底部横向滚动条；各店铺占比图为最右侧百分比预留安全边距；各理疗师占比中的店铺块按当日金额总和从高到低排列。

1 tbook,1,x → 按当天日期、店铺、理疗师和序号快速删除。

⑥ 输入、日期与快捷键
单独一行输入日期（例如 8-7、8月7日、2026-08-07），可指定后续订单日期。
外场转帐快捷输入：name,2/外,1300 自动补全为 name,2,350,60,转帐,1300；序号不加 #，也不额外写“外场”字段。“外1”属于错误输入，不作特殊处理。
Ctrl+T 解析订单或执行 check/chart 查询，不操作剪贴板；Ctrl+Enter 将 textarea 内容复制到剪贴板并执行确认；点击轨道 block 只把订单文字插入 textarea，不操作剪贴板。
从其他软件或浏览器页面切回 Flora 控制台时，会每次自动聚焦订单输入框，使用浏览器普通输入光标，并将页面及输入框内部滚动到当前光标位置，方便看清插入位置并继续输入；每次切回只执行一次，不清空内容。
Ctrl+C 清空输入；Ctrl+S 导出 JSON；Ctrl+U 导入 JSON，先选择“覆盖”或“追加”。
Ctrl+A 录入；Ctrl+W 趋势；Ctrl+L 明细；Ctrl+X 理疗室；Ctrl+D 今日概览；Ctrl+Q 理疗师统计；Ctrl+E Excel折线图；Ctrl+H 或 Ctrl+Alt+H 说明。
Ctrl+, 前一天；Ctrl+. 后一天；Ctrl+M 回到今天（今日概览、理疗师统计及相关时段统计）。Ctrl+[ / Ctrl+] 调整解析日期。
⑦ JSON 导入、Excel折线图与界面空间
